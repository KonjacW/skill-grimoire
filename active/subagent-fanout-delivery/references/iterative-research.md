# 迭代式并行研究（发散 → 收束 → 证伪 → 迭代）

本文件是 `subagent-fanout-delivery` 的第四种形态：**目标未定、没有现成验收判据的开放问题**（多源挖想法、机制归因、方案寻优、参数取舍），预期要跑**多轮**、每轮用上一轮的结论重定下一轮方向。

## 与前三节的分界

判定键是**轮次预期 + 终点是否已知**，不是「只读与否」。三个问题有一条不满足就不要用本形态：

1. 终点已知吗？（要一份文件 / 一次判定 ⇒ 走《产出类 fan-out》）
2. 预期跑几轮？（**一轮能结题** ⇒ 走《只读取证类 fan-out》，那类 ≥3 个只读工作包即默认并行）
3. 每轮之间是否要用上一轮结论**重定方向**？（不需要 ⇒ 走前两节）

**最容易误用的场景**：把「诊断性能异常：扫 3 个目录 + 比对配置 + 审计一个脚本」这种**单轮**只读取证，误当成研究类长驻流程——它同时命中三方症状，本该一轮汇总却被拉成 2–3 波。**「只读」不是本形态的门槛，「要迭代」才是。**

## 本形态新增的四条规则

### 1. 判据预注册

每一波开工前，主 Agent 把这一波的验收判据写进任务卡第一句，形态必须是「可算的量 + 阈值」：`regret ≤ k=H 时的 2×`、`时间比 ≥15×`、`Δthroughput 下界 ≥ −3%`、`偏差 ≤ ±3% 带`、`8 条敏感性轴全过`。
**没有预注册判据的收束等于没收束**——各子代理会各自发明「看起来变好了」的口径，之后的排序就没有共同标尺。

**判据的来源分两层**：**方向与硬门槛来自用户**（用户会说「不达到 N 倍本法就失败」这类话），**可算的数值判据由主 Agent 起草后再请用户拍板**——别把数值当既有事实引用。主 Agent 还可以**自行预注册比验收线更严的装置**（实测：把验收口径从「论文级性能保持」升级为「8 条敏感性轴 × 三指标单侧 95% 下界全过」），用更严的自缚换用户背书，同时堵住「报点估计就算过」。

**时序纪律（预注册的效力全在这里）**：判据与选默认值的规则必须**在批次结果出来之前**写死，并显式禁止事后松动——实测原文写法是「**不允许**在看到结果后再改本节阈值；任何进一步修订必须**写新理由 + 重跑**」，同时预设越界时的**报告形态**（「报 N 倍档的实测代价表 + 满足性能带的最快点」，而不是把门槛改成能过）。判据**整体换代**时（例如目标从 11× 改成 15×），旧轴当场作废、排行榜必须一起重排——预注册保护的是「同一判据不被事后松动」，**不保护判据被替换**。

### 2. 负结果跨波传递

上一波被证伪的路，**原样**写进下一波任务卡，并注明验证方式：

> 「就在你开始规划之后，另一路的终局跑完了，**结果是否定的**（我亲自读了它的产物核对，不是转述）…请并入你的搜索空间判断」

负结果是最容易被丢掉的资产；丢掉，下一波会重撞同一堵墙，而每一撞都是一整轮花费。

**正向数字走同一条通道**：主 Agent 把刚实测到的数字（而不是结论）注入在跑的其它路，让它们在同一口径上继续算；实测一次闭环只用 **2 分 26 秒**（18:22:26 A 路回报 → 18:24:52 主 Agent 把它原样写进 B 路的下一条 steer）。注入必须带**来源与口径标签**（来自哪一批、共享随机数还是独立抽样、真值怎么留出），否则下游对不上账——实测两路读数矛盾，根因就是采样结构不同。

**采纳要有可检痕迹**：子代理把注入的结论当自己前提时，会在回报里单列一段裁定（实测写法：「【steer 裁定】与主对话的相反读数不矛盾，是采样结构差……偏差 0.03% / 1.2%」）。回报里既没有裁定段、也没有复现偏差的，按「未采纳」处理，别当成已同步。

**副作用：「不要重测」会压制交叉验证**。禁止重测能省整轮实验，但也让错口径一路传播——实测主 Agent 两次违规独立复现，才发现自己给下游的读数与子代理的相反。数字进任务卡前先自查口径，或在卡里写「若与你的读数矛盾，报矛盾而不是服从」。

### 3. 长驻子代理 + `steer`（本形态的核心）

不要「派一波、收一轮、再派一波」。子代理在运行期间，用宿主提供的**「向运行中的子代理追加指令」**动作（下称 `steer`）持续注入增量，而不是重派。实测一次成功的多轮研究：`spawn_subagent` 调用 76 次，其中 **steer 46 行（唯一 43）/ spawn 26 行（唯一 21 批）/ list 4**。七类模板：

| 类别 | 何时用 | 模板句式 |
|---|---|---|
| ① 增量输入 | 他路已有实测结论 | 「【主 agent 送来 N 个只读子代理的合并实测结论——**直接当你的新起点，不要重测**】…」 |
| ② 纠偏 | 它的结果与权威口径冲突 | 「【主 agent 纠偏·必须处理后才能继续】你的计时结果与**权威口径矛盾 33 倍**，必须先查清再下任何结论」 |
| ③ 报错分诊 + 一行修法 | 它卡在报错 / 超时（量级第二，实测 ≥8 条） | 「你的脚本挂在 `<文件>:<行>` 的 `<函数>`…**一行修法**：…」／「`exit 127` 是**宿主侧的簿记假象**，不是你的脚本失败」／「根因是**预算超时**：<N> 次调用 ≈ <N> 秒」 |
| ④ 红线 / 否决 | 防止它重复已死的路 | 「给你两条**已经查实的红线**，提机制候选时必须避开：① **<某方案> 已否决** ✗…」 |
| ⑤ 目标重定价 + 止损 | 目标变了 / 该收口了 | 「**收尾指令**：你的目标已被重新定价，请立刻收敛。你已运行 **91 分钟**（是本轮最长的一路）」 |
| ⑥ 环境广播 | 凭证 / 路径 / 依赖类阻断 | 「【环境修正，避免你白跑一轮】<某项> ✗ 指向不存在的文件…**已有一位子代理因此白跑一轮**」（**一条发给所有在跑的**） |
| ⑦ 自我作废 | 主 Agent 自己上一条判断错了 | 「我上一条『<判断>』**作废** ✗，真正的原因是你把阈值写死了」 |

限制与坑（五条）：

- 类与类**不互斥**（一条 steer 可同时命中①②④）。
- `steer` **不能改结构性约定**（产物路径、返回 schema、任务边界）——那类必须重派。
- **`steer` 是单目标**：所谓「广播」是对每个在跑的子代理各发一次（实测同文 2–3 条一组），不是一条命令打到所有路。
- **发给已结束的子代理会静默失败**：宿主返回 `No live subagent 'sa-N-…' in this conversation's spawn tree`，纠偏**不会送达**（实测 6 个会话共 7 处）。发之前先确认它还活着——控制动作里的 `list` 是常态开销，别省。
- 成本已实测（见《并行成本刻度》）：重派 ≈ steer 的 2.7–64×，所以「长驻 + steer」这条路线划算；但**不要引用成「steer 免费」**——单条真实边际成本中位 ≈ $0.0010，其中 93% 是那一轮的缓存重发。
- **量化形态（自查是否走样用；数字来自同一次实测）**：
  - **时机双峰**：一批 steer 落在派发后 ≤2 分钟（补票式——把刚想到的红线 / 环境事实补进正在跑的卡），另一批落在 10–40 分钟（已有中间产物之后）。**口径要写明**：按「时间上最近的前一个派发行」算，实测 min 0.6 / 中位 14.9 / max 52.4 分钟；按「同批派发行」算会得到另一组数（中位 20.7 / max 96.6），两者不可混用。
  - **同一目标可连发多次**：27 个目标里 1 次 ×16、2 次 ×8、3 次 ×2、5 次 ×1；最长一路在 1 小时 36 分钟内收了 5 条 steer、跨 4 类用途、全程有效。给序列编号（`steer #2` / `#3`）能把单向投递变成逐步收窄的问答链。
  - **形态固定**：43/43 条以 `【代号·标签】` 标题开头、带加粗小标题与编号 / 勾叉判定，长度中位 1116 字符（427–2236）。长条是「背景 + 编号要求 + 口径 + 判定」的成建制包；短条是单点纠正（只讲一个环境变量或一个报错根因）。
  - **「广播」不是同文复制**：完全相同的正文组数实测为 **0**——写法是「固定事实块 + 逐目标定制尾段」（三条共同前缀 393 / 355 / 355 字符），每条都要求对方给出自己主题下的判定。按「谁会受影响」筛目标**会漏**：实测一次许可证类环境修正发了 3 路，同批第 4 路全程没收到 ⇒ 那一轮白跑。
  - **撤回要追发**：主 Agent 撤回一条数字后，该数字仍在下游被当权威继续引用（实测 6 小时后仍出现在另一路的结论里），直到补记「口径分歧警告」才停。撤回必须发给**所有引用过该数字的活体路**，并在文本里点明「撤回哪一条、替换成什么」。

### 4. 证伪波必配

每 1–2 个发散波配一路**对抗性**子代理，任务卡写死「**任务性质=证伪，不是附和**」：逐条复算主 Agent 与同伴的关键数字，回三态结论「**复现 / 不符 / 无法判定**」，不符必须给出自己的数与差异原因。可另设一路常驻「审计员」循环审计其它路的产出（判拟合常数、过拟合风险、统计依据）。
一个假的性能保证比没有保证更危险——把「无法判定」与「判定为假」严格分开。

**阻断项要有处置阶梯，不能只记一条结论**：本形态把「缺乏统计依据的性能保证」记为阻断（价值判断见上一段：一个假的保证比没有保证更危险），并**不因此放弃机制**——把「保证」与「机制」解耦：保证被证伪则机制保留、退回无保证版。三件套处置（回炉补基础 / 预约定降级形态 / 写明解除条件）的**唯一副本在 `review-gate` 的《阻断项处置》一节**，此处不复制。

**执行率的实测反例（别以为写了规则就等于做到了）**：一次跨 4 个波的长会话里，专职「任务性质=证伪」的 brief 只有 **2 条**、常驻审计员 1 条，**且全部集中在同一个波**；其余三波没有任何独立证伪角色，三态结论格式也只在那一批出现。派发前扫一眼：**这一波有没有对抗性一路？**没有就补，别等下一波。

## 一批的固定节奏

```
① 立项：命名（前缀 + 序号；续波加 `R` = 接着前任产物续跑、不重写）+ 硬判据（预注册）
② 任务卡：一包一轴 + 产出下限 + 产物唯一路径 + 预算上限 + 「先落盘骨架」+ **不得留未展开的占位符**
   （判据与宿主报错形态见 `subagent-fanout-delivery/SKILL.md` 铁律 4 的「字段纪律」⑥；
    任务卡必写项与骨架要求见前几节，不复述）
③ 派发：n=3~5；发完立刻收工，本回合不再干别的（有 8 条在跑时不再新开波）
④ 运行期：用上面七类 steer 持续注入新事实 / 纠偏 / 红线 / 环境修正 —— 本形态独有（子代理起的后台实例，其状态会**带归属前缀回流到主对话**，形如「`Started by subagent … of delegation …` … `exited (exit code 1)`」（**宿主原始文案，贴出来只为形态识别**）；据此判断哪一路实例倒了，比反复 `list` 更实时）
⑤ 收束：排序 → 选可执行候选 → 预注册下一波判据（重排前先 `list` 清存活——它只回存活与目标、不含进度，「还活着」≠「有效」）
⑥ 证伪：每 1–2 波派一路对抗性审计（三态结论）
⑦ 台账：更新汇总文件（新事实 / 被推翻的旧结论 / 下一步）；**汇总必须单列一节「主对话还不知道的新事实」**（用户既有的报告契约；子代理回报只写结论与出处，不复述片段全文）；负结果按规则 2 传给下一波
```

## 一轮的时限与规模刻度（实测）

顺序之外还有**时限**，缺了会退化成「等证据齐了再动」：

| 动作 | 实测刻度 | 依据 |
|---|---|---|
| 授权 → 派发 | **≤5 分钟**（实测 43 s / 50 s / 68 s / 73 s，另有一批 ≤255 s） | 授权到手越快出波越好——波一开，方向就锁定了 |
| 派发 → 批次表 | **8–26 秒**：派发行只含一个派发调用，随后立刻出「已发出 + 编号 / 产物目录 / 否决线 / 优先级」汇总，然后本回合收工 | 派发即定契约，后续 steer 只引用代号 |
| 一批回报 → 收束三件套 | **≤2 分钟**（实测 102 秒）：合并成一篇事实 → 写进计划文件对应小节 → 反向 steer 喂在跑的路 | 不落盘的收束等于没收束 |
| 在飞批次数 | 有 **8 条在跑**时明确不再新开波（「再加会稀释 steering 质量」）；判断某路该不该引导，看它的**实际动作**而不是运行时长 | 单批宽度上限见 `using-superpowers` 的《并行的成本门槛》（单批 n≤6）；**本行的 8 是在飞路数（含上一波长驻），与单批宽度不是同一个量** |
| 续波后缀 | `R` = **接着前任的产物续跑、不重写**；任务卡点名前任产物路径 | 实测 P1–P5 → P1R–P5R、P6/P7 → P6R/P7R |
| 代号唯一性 | 前缀会跨波复用（同名 `D1–D6` 与 `D1–D4` 是两批不同东西）⇒ 代号必须带日期或序号区间 | 否则台账无法消歧；「波」也别用聚类代替批次 |

数字来自一次 34 小时长会话的导出账本实测，每条都能按消息 id / 时间戳回查；口径 = 以「派发行 / 回报行」为计时起点的**单次采样**，不是分布统计——别把单次值当分位数用。

**两段式派发（规划者 → 执行者）**：开放问题的下一波不必直接派实现者——先派 **1 路「规划者」**，产出「按价值排序 + 每条含机制 / 预期收益 / **数值化否证线** / 最小验证实验 / 失效条件」的提案清单；下一波只把其中一条交执行者，任务卡写死「**你不必从零设计**——一位规划者已把方案写完并带数值否证线，你的活是把它钉死」。执行者重新发明一遍方案的代价，比多派一路规划者贵得多。

## 无人值守发散（自动进场后的硬护栏）

适用：agent 在没有人在场时（长任务挂载、后台批次、用户离线）命中《一次并行判断》C 档。**自动进场不等于无上限**——无人值守时没有人能叫停，唯一的停止装置必须**写死在任务书里**。开始前把「授权范围」落盘：可读 / 可写目录、可否自行派发、预算上限、波数上限、绝对禁止的动作。

**默认授权**：命中 C 档判据、且预算与波数都在上表上限内时，**可以自行派发，不必再等一句「授权」**；只有任务书显式写着「不要派发子代理」时，才降级为单 agent 多轮（仍须预注册判据、每轮落盘、最后收束出报告）。

**默认值（写死；用户可在任务书里覆盖，agent 不得自行放宽）**

| 项 | 默认 | 依据 |
|---|---|---|
| 单批宽度 | **n=3**（不超过 4；单批硬上限 n≤6） | 宽度 2 中位仅 1.73×、最低 0.84× ⇒ n<3 不派；无人时取小值降峰值与协调成本 |
| 单路预算 | **$0.09 封顶**，到界即发收尾指令 | 实测子代理单路花费 $0.082–0.089 |
| 总预算与波数 | **≤3 波 / 约 $1.2**，到界必须收束出报告 | 时间与金钱脱钩，墙钟不能用来估预算 |
| 每波收束 | 波末必须落盘：排序 + 选可执行候选 + 预注册下一波判据 | 不收束就加波会稀释引导质量 |
| 证伪 | **每波 1 路专职证伪**（无人值守不适用「每 1–2 波」的宽限） | 没人复核时，假保证的风险最高 |
| 止损 | **连续 2 轮无新发现即收束**；单路超时或 91 分钟级长跑且目标已被判无害 ⇒ 发收尾指令 | 实测停止规则 |
| 负载 | 高占用负载**不许在本机跑**，放远程执行环境；本机只留轻量探针 | 本机不是重活场地 |

**必须落盘（否则等于没跑）**：① 派发前的预注册判据；② 每波任务卡与产物唯一路径；③ 候选表——每条含机制 / 预期收益 / **数值化否证线** / 失效条件；④ 被证伪的路（负结果）以及它传给了谁；⑤ **单列一节「还不知道的新事实」**（用户不在场，这是唯一的交接面）；⑥ 未检查清单；⑦ 波数与花费记账。

**无人值守下的绝对禁止**：push / 新建远端 / 任何删除 / 改授权范围外的目录与配置 / 动用户在用的实例与资源。需要这些动作时**停下来写进报告**，不替用户拍板。

**降级路径（触发护栏别硬跑）**：预算到界 ⇒ 收束出报告，并标明「未探索的方向 + 建议下一步」；环境异常（额度、网络、进程被回收）⇒ 渐降并发直到 1 路，先把已有结论落盘，不硬停、也不静默重试。

### 闲时发散（把等待窗口用起来）

适用：主 Agent 在等**自己控制不了的东西**——长批次 / 仿真结果未回、已派出的子代理未回、外部服务未响应——本轮没有别的可推进步骤，但手上信息足够（已有基线 / 剖面 / 历史记录），且命中 C 档 ≥3 条判据。**空转轮询与干等都不产出**，把窗口用来发散。

与无人值守的差别（都更保守，因为在跑的东西随时会回来）：

| 项 | 闲时默认 | 理由 |
|---|---|---|
| 波数 | **1 波**；等待对象一到即收束，允许中途被收束（用现有中间产物） | 窗口长度不可知，别把长驻当默认 |
| 宽度 | **n=2~3** | 收束要快、协调成本要低 |
| 负载 | **只读 / 离线优先**；不许占用被等待工作所需的资源（本机 CPU / 内存 / 端口 / GPU）；重负载一律去服务器 | 别把正在跑的批次拖慢或拖崩 |
| 预算 | 单路 $0.09 封顶，总预算按单波上限 | 与其它形态同一刻度 |
| 产物 | 写**独立位置**，**不得改动主交付物** | 等待期间的未验证结论不能污染正在交付的东西 |
| 收束 | 排序 + 选候选 + 预注册下一波判据 + **明确写出「等待期间新增了什么」** | 等待结束时主 Agent 只有一个动作窗口 |
| 升级 | 等待窗口被外部确认为长时间（例如已告知的长批次）⇒ 按《无人值守发散》的上限跑，不必压到 1 波 | 别把长窗口浪费掉 |

**闲时发散的常见浪费**（都实测过）：① 干等/反复轮询状态而不产出；② 抢本机资源跑重活，把在跑批次拖慢；③ 把等待期的未验证结论直接写进主交付物，等真结果回来才发现口径不同；④ 派出去就不管，等结果回来时子代理还在跑、只能丢弃。

## 并行成本刻度

**唯一权威副本在 `using-superpowers` 的《并行的成本门槛》一节，此处不复制**——本形态刚因为「同一张表存两份」被一次独立 Review 判为漂移源。本形态只需记住与本形态直接相关的三条：

- **单批 n ≤ 6**（加速比中位 ≈0.75×n，n≥7 掉到 0.58×n）；**n<3 不派**（宽度 2 中位 1.73×、最低 0.84×）。
- **单路预算按 $0.09 封顶**（实测子代理单路花费 $0.082–0.089）；到界就发 ⑤ 收尾指令。
- **`steer` 比重派便宜**（实测：重派 ≈ steer 的 2.7×（只算开机）/ 13×（比最便宜的整单）/ 64×（比中位整单））——这正是本形态把「长驻 + steer」当核心的量化依据。**但 structural 约定改不动时必须重派**（见规则 3 的三条限制）。

另有两处最容易算错的口径，已在那一节里；此处只列标题：**单位成本的分母有字段/实计数两种取法（差 2 倍）**、**「末位派发后的批墙钟」不等于「其余路干等最后一路」**。
