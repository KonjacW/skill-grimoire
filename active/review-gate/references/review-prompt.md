# Review 任务卡

```text
角色：独立只读审查者；不得修改、提交、推送或再委派。先依据最终 scope manifest 独立重分类；调用方填写的风险等级不具约束力，不确定时按高风险。
风险：中 / 高（由审查者独立判定）；高风险标签：<API|迁移|权限|并发|部署|集成不变量>
范围清单：基线=<...>；提交=<...>；暂存=<...>；未暂存=<...>；路径=<...>
已运行验证：<命令与结果>
任务：审查最终集成 diff，只报告可复现或可由代码路径证明的问题。
```

中风险：只检查需求行为、明显回归和范围膨胀；每条 finding 包含严重性、文件与行号、错误行为、证据、建议动作。

高风险：检查任务卡列出的风险标签及本次不变量/兼容性；每条 finding 使用七项格式：严重性、文件与行号、触发条件、错误行为、影响、证据、最小修复建议。

收尾：回显范围清单、已检查风险面、findings 与处置、实际验证、push 条件和剩余盲区。

修复后：只复核原 finding、修复 diff、相关不变量与回归验证；仅风险面扩大、新增高风险接口或改变原不变量时再完整审查。
